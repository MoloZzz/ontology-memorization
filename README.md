# LLM будує таксономію: розуміння чи пам'ять?

Практична частина до доповіді «Онтології та LLM» (слайди 11 і 22).

## Ідея

У LLMs4OL (ISWC 2023) GPT-3.5 набрала 91,7% на WordNet. Але WordNet публічний десятиліттями й майже напевно був у навчальних даних моделі. То модель **розуміє** ієрархію понять чи **пам'ятає** WordNet?

Перевіряємо прямо. Задача: для поняття обрати його безпосередній надклас із 5 варіантів (як Task B у LLMs4OL). Ті самі 60 понять у трьох умовах:

| Умова | Що бачить модель |
|---|---|
| `real` | справжня назва + визначення |
| `renamed` | вигадане слово + те саме визначення |
| `name_only` | лише справжня назва |

- `real ≈ renamed` — модель міркує зі змісту визначення.
- `real ≫ renamed` — успіх тримається на знайомій назві, тобто на пам'яті.
- `name_only` показує, скільки модель знає взагалі без підказок.

Щоб тест був чесним:
- у жодному визначенні немає назви правильного надкласу, тож відповідь не можна просто знайти в тексті;
- неправильні варіанти — «сусіди» правильного надкласу в ієрархії WordNet, а не випадкові слова;
- `temperature=0`, а відповіді кешуються, тож повторний запуск безкоштовний і дає ті самі числа.

## Запуск

```bash
pip install -r requirements.txt
python -c "import nltk; nltk.download('wordnet')"

# 1. Перевірити, що все працює, без API (числа ФЕЙКОВІ)
python experiment.py --mock

# 2. Справжній запуск: 60 понять × 3 умови = 180 запитів
export OPENAI_API_KEY=sk-...
python experiment.py --model gpt-4o-mini
```

Підходить будь-яке OpenAI-сумісне API, його задають через `OPENAI_BASE_URL`:

```bash
# Локально й безкоштовно через Ollama
export OPENAI_BASE_URL=http://localhost:11434/v1 OPENAI_API_KEY=ollama
python experiment.py --model llama3.1:8b

# Більше понять — стабільніші числа
python experiment.py --n 150
```

Результати лежать у `results/`:
- `report.html` — звіт: відкрий у браузері, саме його показуєш;
- `chart.png` — графік;
- `raw.csv` — кожна відповідь моделі;
- `summary.json` — підсумкові числа;
- `dataset_*.json` — набір питань, однаковий для всіх моделей.

**Найцікавіше — запустити дві моделі**, наприклад маленьку локальну і `gpt-4o-mini`, і порівняти розрив між `real` і `renamed`.

## Демо (3–5 хв)

1. **Задача.** Відкрий `results/dataset_*.json` і покажи одне поняття в трьох умовах: «sandwich» проти вигаданого слова з тим самим визначенням.
2. **Запуск.** `python experiment.py` з кешем відпрацьовує за секунди.
3. **Звіт.** Три числа, графік і таблиця прикладів, де модель вгадала зі справжньою назвою, але помилилася з вигаданою.
4. **Висновок одним реченням:** «Розрив між real і renamed — це частка результату, яку модель бере з пам'яті, а не з розуміння. Тому бенчмарки на WordNet завищують здатність LLM будувати онтології».

## Обмеження (на випадок питань)

- WordNet допускає кілька надкласів, і деякі неправильні варіанти можуть бути спірними: наприклад, «pot» → «kitchenware». Шум однаковий для всіх умов, тому порівнювати умови між собою коректно.
- Вигадане слово прибирає назву, але не прибирає знання про саме визначення. Тест вимірює внесок назви, а не всієї пам'яті.
- 60 понять — це похибка приблизно ±6–12 п.п. Для висновків краще `--n 150` або більше.
